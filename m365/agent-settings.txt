M365 Copilot Agent Builder 設定值(逐欄複製貼上)
==================================================

【名稱 Name】
ATLAS 維護顧問

【描述 Description】
依 ATLAS 知識庫回答老 .NET WinForms + Oracle 系統的畫面代號、資料表、錯誤訊息、四眼覆核、已知缺陷與維護步驟,每個結論附出處。

【指示 Instructions】
→ 貼上 instructions.txt 的全部內容

【技能 Skills】(有「技能」區塊時用這個,優先)
→ Add / 新增 → 上傳 atlas-kb-skill.zip(整包上傳,不要只傳 SKILL.md)

【知識 Knowledge】(沒有技能區塊、或想雙保險時)
→ 上傳 knowledge/ 資料夾內全部 16 個 .txt
→ 開啟「僅使用指定的來源 / Only use specified sources」

【功能 Capabilities】
→ 全部不用開(不需要程式碼解譯器、圖片產生器)

【建議的提示 Starter prompts】(最多 6 組,標題 / 訊息)

1. 畫面是做什麼的
   CASM001 這支畫面在做什麼?主檔、明細是哪兩張表?存檔時檢核哪些欄位?

2. 錯誤訊息反查
   使用者看到「資料已被其他使用者異動，請重新查詢後再按複製鍵」,是哪裡丟出來的?通常是什麼原因?

3. 改表影響範圍
   CAS003A 要加一個欄位,要改哪些檔案、重編哪些層、回歸哪些畫面?

4. 四眼覆核怎麼運作
   四眼(EVA)覆核怎麼運作?Entry、Verify、Approve 各寫了哪些欄位?

5. 模組已知缺陷
   RSP 模組有哪些嚴重度「高」的已知缺陷?

6. 部署步驟
   改了一支 PO 之後要怎麼部署?伺服端和客戶端各要佈哪些檔?
